# 朱简(zhujian)

> [English](readme.en.md) · **简体中文**

朱简是一个记想法、管待办的工具。想到什么,先记进随记;要做的事转成待办,一步步推到完成。数据存在你自己的设备上,不联网也照常用。

![朱简的任务看板:待办 / 进行中 / 待确认 / 已完成四列](site/shots/desktop-board.png)

- **下载**:Windows 与 Android 是正式版,在 [zhujian.app](https://zhujian.app);macOS 与 Linux 是尝鲜版。
- **免费使用 · 开源(MIT)** · 不用注册。
- **没有 AI 功能,也不依赖大模型**:从记下到做完,每一步都由你自己动手。

> 产品里没有 AI;产品是我和 AI 一起写的。

名字取自「朱砂」与「简牍」:朱色书写,竹木短简记小事,「简」亦取简朴意。原名「朱笺」,后来改叫朱简,更好认。

```
记一笔 → 随记 → 转成待办 → 看板上做完
```

要想清楚再用的那几件事(备份码、移除设备、同一个 Wi-Fi 下直连的代价、自定义列的版本门、勾选在离线时的冲突),都写在[用户指南](docs/user-guide.md)里,一件不藏。

## 功能

### 记一笔

- 有些事想起来就是一句话,当时来不及整理。朱简先接住这一句话:打开就是输入框,写完收起,不打断你正在做的事。
- 电脑上按 `Ctrl+Alt+N` 唤出一张纸条,写完回车就存进随记,窗口自己收起;`Ctrl+Alt+M` 打开主窗,停在你上次离开的视图。两个热键都能在「设置 → 快捷键」里改(和别的软件撞了就换一个,撞键也不会让程序起不来)。也可以双击系统托盘图标打开主窗,右键看菜单。
- 手机上点底部的圆钮就能写,写完点「记下」回到列表。
- **可以配图**:电脑上截图直接 `Ctrl+V` 粘进去,手机上用「加图」从图库选、「拍照」当场拍一张。一条可以配多张,图片带「图1」「图2」的编号,点开看大图。
- **正文里的小清单**:行首写 `- [ ] 买牛奶`,会画成一个可以点的方框,点一下打勾,勾过的那一项文字变淡。适合把一件事拆成几小步。
- 电脑的捕获纸条里,行首打 `/` 唤起命令:`/task` 把这条直接存成任务、`/tag 家庭` 给这条挂标签、`/space` 换个空间落点。普通以 `/` 开头的正文(比如 `/etc/hosts`)不会误触发。

### 随记

- 记下的内容按天排成一条时间轴,今天、昨天、更早,一眼看到自己这几天在想什么。
- 内容多了可以按标签筛、也可以打字过滤,两者能叠加。
- 每一条都能编辑,改之前的旧版本会自动留一份,原文不会被覆盖掉。
- 删除是软删,先进回收站,想找回来随时还原;真要销毁,在回收站里再确认一次。
- 打过标签和没打标签的随记在同一个列表里,标签只是顺手的元数据。

### 转成待办 · 任务看板

- 想清楚了的随记,一键转成任务,它就离开随记、进入看板。同一条内容换个档位,不产生副本;「待办」也能撤回为随记。
- 看板默认四列:**待办 / 进行中 / 待确认 / 已完成**。拖动就能改状态,也能在列内调顺序。
- 「待确认」是留给「我做完了,在等对方回音」的那类事,用不上可以改名或删掉。
- **列可以自己改**:在电脑上「管理列」可以新建 / 改名 / 调顺序 / 删除,列会同步到你的其它设备。
- 每张卡可以设截止日期、优先级和标签;逾期和今天到期会标出来。顶部一枚汇总钮写着「逾期 M · 今天 N · 3 天内 K」,点一下把看板收成只剩这些卡。电脑上还能让应用每天到点发一条系统通知报这两个数。
- 「已完成」的卡上写着**完成于**哪天,撤回或归档都保住这个时刻。
- 做完的任务**归档**,按完成那天排成时间轴,可查、不可删(要删先取消归档回看板,多一步,防冲动)。归档不是删除,和回收站各走各的门。
- 电脑上鼠标移到卡片,右上角 ⋯ 弹出操作速查,每项标着单键:编辑 `E` / 复制 `C` / 标签 `L` / 截止 `S` / 优先级 `P` / 撤回 `B` / 删除 `D` / `]` 后移一列 / `[` 前移一列。双击卡片 = 编辑。同一套交互随记卡也用。

### 标签

- 轻量分类,一条内容可以挂多个标签。
- 标签列表上显示每个标签底下有几条随记、几个任务,点开就地展开看。
- 人工新建 / 重命名 / 删除 / 合并(把碎标签并成一个);拖手柄可以调顺序,你排的顺序到处都跟着。
- 可以给标签点个「类型」(自由文本,比如标成「人名」),方便日后按类型归拢。
- 想分层就用斜杠命名,比如「工作/汇报」,它会缩进显示在「工作」下面。

### 搜索

- 按内容跨随记、任务、回收站、归档一起找,连改过的旧版本也一起搜,匹配高亮。

### 多空间

- 一个空间就是一本完全独立的册子:各自的随记、看板、标签、搜索,各自的同步账户。
- 比如「个人」和「家庭」分开记,互不混排;记错地方的那一条可以「移动」到别的空间。

### 多设备同步(可选)

- 电脑、手机之间同步随记和任务,默认走官方服务器 `sync.zhujian.app`,也可以在设置里换成自建的;不配置就完全离线使用,这个功能全程沉默。
- 不要邮箱和手机号:第一台设备点「创建账户」,拿到一串**恢复码**;其余设备输入配对码加入,自动拿到全量数据。
- 内容在本机加密之后才离开设备,服务器只经手密文、看不到你写了什么。
- 两台设备在同一个 Wi-Fi 下会自动点对点直传,更快,而且路由器断了外网也照样同步。
- 同步面板里有一张这个空间当前的**设备名单**,可以给每台起个名字,条目上会淡淡标出是哪台记的。

### 外观

- 明暗三档:跟随系统 / 一直亮 / 一直暗。只影响这台设备,不会同步到别的设备上。
- 界面字号也是这台设备自己的事:电脑上 `Ctrl +` / `Ctrl -` / `Ctrl 0`,手机上在「设置 → 界面字号」里选。

### 这一版没有什么

诚实说清楚,免得你装了才发现:

- 没有广告、没有开屏、没有推送通知、没有会员和内购。
- 不看你的位置、通讯录、短信、通话记录,也不读你的相册:手机上选图片走系统的选择器,只拿你点的那几张。
- 不接第三方统计、不做用户画像、不做个性化推荐。
- 加密备份目前只有电脑端,而且只能手动点一次备一次;定时自动备份与一键恢复还没做。
- 电脑上装好后会自动检查新版本并提示你;手机上提示之后要你自己点一下装。

### 价格

免费使用,含多设备同步,没有内购。

### 关于数据

- 你的内容存在这台设备上。手机上卸载应用会连数据一起清除;电脑上卸载不会删掉数据目录和备份钥,要手动清。哪一种都请先做好你自己的备份。
- 不开同步时,应用只会连 `zhujian.app` 查有没有新版本,别处一概不连。
- 「数据不丢」指的是这个软件不会静默地弄丢你写的东西(编辑留历史、删除进回收站),它不等于设备坏了还能找回来,那需要你自己保留另一份副本。

## 技术栈

| 层 | 选型 |
|---|---|
| 桌面外壳 | Tauri v2(Rust 后端 + WebView 前端) |
| 前端 | Vite + TypeScript(原生,无框架) |
| 存储 | SQLite(rusqlite,bundled) |
| 唤起方式 | 全局热键(可改键)+ 系统托盘;两个窗口默认不可见 |

## 开发

前置:Node、Rust(rustup stable-msvc)、WebView2 运行时、VS2022 C++ 工具集。

```bash
npm install          # 前端依赖(含 Tauri CLI)
npm run tauri dev    # 启动开发模式(同时起 vite:1420 + app)
npm run tauri build  # 打包发行版(release,把前端嵌入独立 exe)
```

> ⚠️ **别直接运行 `src-tauri/target/debug/app.exe`**:debug 版的 WebView 指向开发服务器
> `localhost:1420`,未先起 vite 会显示「localhost 拒绝连接」。开发请用 `tauri dev`,
> 需要独立可执行文件请用 `tauri build`。
>
> 应用是托盘程序,两窗口默认 `visible:false`,从托盘双击(或右键菜单「打开朱简」)、
> 热键 `Ctrl+Alt+N`(捕获)或 `Ctrl+Alt+M`(打开主窗)进入。

## 测试 / 验证

- **逻辑**:`cd core && cargo test`(全部后端测试在共享 crate `zhujian-core`,含历次数据迁移零丢失的折叠验证、同步引擎收敛 property test、对真同步服务器的双库端到端集成测)。另有独立 crate:`cd src-tauri && cargo test` / `cd sync-proto && cargo test` / `cd server && cargo test` / `cd android/src-tauri && cargo test`。
- **真 GUI e2e**:`npm run test:e2e`,WebdriverIO → tauri-driver → msedgedriver → 真 WebView2,跑真点击 + 真 IPC + 真 SQLite。
  - **fast(日常迭代)**:先在另一终端 `npm run dev`(**只起 vite,别用 `tauri dev`**,它会抢全局热键 `Ctrl+Alt+N` 致 e2e 的 app panic),再 `YS_E2E_FAST=1 npm run test:e2e`。
  - **release(最终把关)**:`npm run tauri build -- --no-bundle` 出 release exe 后 `npm run test:e2e`(默认,自包含无需 vite);同样先停 dev。
  - 隔离:e2e 用临时库 `%TEMP%\ys-nb-e2e.sqlite3`(每次清空),**不碰真实笔记本**。
  - 依赖:`tauri-driver`(`cargo install tauri-driver`)、`e2e/drivers/msedgedriver.exe`(**仓库不含**,自行下载与本机 WebView2 运行时**同版本**的 Edge WebDriver 放到该路径)。
- **看库**:`node --experimental-sqlite scripts/verify-db.mjs`;数据库位置 `%APPDATA%\app.zhujian.notebook\notebook.sqlite3`(可被 `YS_DB_PATH` 环境变量覆盖,e2e 用)。

> 若所在网络访问 crates.io 困难,可自建 `.cargo/config.toml` 配置代理(仓库不含此文件,
> 属机器本地配置)。

## 数据模型要点

- 主键全为 **ULID**(TEXT),时间戳为 RFC3339 UTC TEXT;`due_on` 例外,是用户本地日历日 `YYYY-MM-DD`(截止是「日历日意图」,不存 UTC instant 以免差一天)。
- **单实体**:想法与待办是**同一行 `items` 的不同 `stage`**(`inbox 未归类 / filed 已归类 | todo / doing / confirming / done`),不是两条记录。**转待办 = 翻 stage 到 todo(零副本)**,撤回 = 翻回 inbox/filed;任务态条目不出现在随记视图(天然去重)。`archived_at` 是回收站轴(冻结 stage、还原回原档),前端按冻结 stage 分「随记回收站 / 任务回收站」。
- **概念隔离**:`items.stage` = 流程档位(随记↔任务)/ `topics` + `item_topic`(M:N)= 标签(对用户即「标签」;任务也是真多标签,筛选时在每个所属标签下都出现)。
- **不可变性是历史级**:用户**可以编辑**自己的条目,每次改动前的旧版本由 DB 触发器自动归档进 `item_revisions`(append-only、不可改写),**覆盖全 stage**(改任务标题也归档)。唯一的例外是**纯勾选变更**(正文里只有方框那一个字符变了,migration 0039):判据写在 `core/src/checklist.rs`,只许往窄里写。
- **删除是用户主权,但分级 fail-safe**:防的是「意外 / 静默毁数据」,不是禁用户清理自己的数据。**删除 = 进回收站,销毁只在回收站里发生**:【删除】都是软删(盖 `archived_at`、可还原回原档)→ 回收站二次确认才彻底删(cascade 标签与历史)。随记与任务共用这一条 archived_at 轴;存储层删除守护照旧,已归类的想法 / 任务在数据库层面就硬删不掉活跃行。
- **`topics`(标签)是可重算派生投影**:手动合并(`merge_topics`)重写 `item_topic` 归属,把碎标签并入存续标签、不保留 membership 历史,不丢 item、不碰 content。
- 每连接 `PRAGMA foreign_keys = ON`;关联表 `ON DELETE CASCADE`。不加 metadata JSON 万能列;扩展靠显式迁移(`core/migrations/` 里一条一个编号,只增不改)。

## 设计铁律

- **纯人工**:想法的每一步流转(打标签 / 转待办 / 撤回 / 删除)都是用户亲手发起的事务,没有任何自动判断替你做决定。
- **fail-fast**:产品代码绝不写静默回退 / 兜底默认值;非法操作整事务回滚并报错。
- **只保「数据不丢失」类保证**:历史归档、禁直删已归类条目这两道守护保留;为防系统静默改数据而设的「流转锁死」类触发器已撤掉,换取灵活与低维护成本。
- **风格**:轻量 / 最小化 / 纸与朱墨(暖纸面 + 浓墨 + 朱砂点缀;想法原文用衬线,界面文字用黑体)。
