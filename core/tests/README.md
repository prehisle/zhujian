# 为什么这里有一份 README(而目录是空的)

本目录今天没有任何测试,但它被这份文件钉在 git 里,原因有两条:

- `core/src/test_temp_cleanup.rs` 的扫描面锚(`ROOTS`)要求它存在——那只锚是
  fail-closed 的(「路径写错 = 什么都没扫到」是最经典的静默变绿方式,所以目录缺席
  = 当场红)。此前它只存在于作者本机(git 不追踪空目录),于是任何 fresh clone 上
  `cargo test` 必红这一条。2026-08-08 定案:钉进仓,而不是从 `ROOTS` 删行——删行的
  代价是哪天真建了 `core/tests` 得记得回来加回去,忘了就是静默不扫。
- cargo 约定 `tests/` 放集成测试:哪天往这里放 `*.rs`,它自动成为测试目标,也自动
  落进上面那道锚的扫描面,不需要改任何清单。
