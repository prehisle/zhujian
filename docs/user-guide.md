# 朱简 用户指南

[readme](../readme.md) 讲的是「有什么功能」,这一份讲的是**要想清楚再用的那几件事**:哪些操作不可逆、哪些东西丢了找不回来、多设备一起用时各自看得见什么。

一件不藏,所以有点长。真正要紧的只有几处,标着 ⚠:**账户密钥在哪**、**备份码**、**移除设备**、**同一个 Wi-Fi 下的直连**。

## 数据在哪

- 你的内容存在**你自己这台设备**上,是一个 SQLite 数据库。不联网也照常用。
- 电脑上在 `%APPDATA%\app.zhujian.notebook\`;手机上在应用自己的私有目录里。
- 不开同步时,应用只会连 `zhujian.app` 查有没有新版本,别处一概不连。
- 每个**空间**是一本完全独立的册子,各自的随记、看板、标签、搜索,各自的同步账户。
- 想把内容拿出去(存一份文本、喂给别的工具):电脑上随记页顶栏【复制随记】、看板页【复制看板】、列头【复制】都是复制成 Markdown 到剪贴板,复制的是**当前筛出来显示的**那些。没有导入。

## 编辑历史:什么会留一版,什么不会

- 每次编辑之前,改动前的那一版会自动留一份,原文不会被覆盖掉。搜索也搜得到旧版本。
- **例外只有一个**:正文里的勾选方框,点一下打勾**不留历史**。理由很实:一个八项的清单从头勾到尾,会长出八条只差一个字符的历史版本。判据只认「这次改动是不是只有方框里那一个字符变了」,只要还动了别的字,照旧留一版。
- ⚠ **勾选在离线时会冲突**:两台设备在**都没联网**的那段时间里,各自勾了**同一条**里的不同项,后同步上来的那一份会盖掉前一份。丢的是勾选状态,**不会丢文字**。

## 删除、回收站与归档

- **删除 = 进回收站**,不是销毁。随记卡的【删除】不弹确认(反正找得回来),任务卡首次会确认一次。
- 真要销毁,去回收站【彻底删除】,那一步要再确认一次。彻底删除会连带删掉这条的标签归属、编辑历史和配图。
- **归档不是删除**,两边各走各的门。做完的任务归档之后**可查、不可删**;真要删,先【取消归档】回看板,再走正常删除,多这一步是故意的。
- 归档视图按**完成那天**分组,不是按入档那天,所以一次归档一周的活不会全压在今天。

## 配图与「图N」编号

- 一条可以配多张图。每张缩略图带一个「图1」「图2」的角标,正文里写「图1」会自动变成可点链接跳到那张图。
- **编号是图的身份证**:删掉某张图之后,剩下的**不重新编号**(留一个洞),这样正文里的引用永远指向同一张图。换图 = 删旧的、加新的。
- 图片随条目一起进回收站、一起还原、一起被彻底删除。
- 手机上从图库选的原图动辄好几 MB,存之前会自动缩到合适尺寸;截图和小图原样保留。

## 正文里能写什么

- **只有一种 markdown 写法有效**:行首 `- [ ] 事情` 画成可点的方框。粗体、标题、代码块一律不识别,这是「正文里能勾几个框」,不是一个 markdown 编辑器。
- 想写普通列表就写 `- 事情`(不带方括号),它不会变成方框。
- 正文里的 `http(s)://` 网址会变成链接:左键用系统默认浏览器打开,右键复制链接。

## 任务看板与自定义列

- 默认四列:待办 / 进行中 / 待确认 / 已完成。各列之间自由双向流转,可以打回重做;「待确认」用不上就改名或删掉。
- 只有「待办」能【撤回为随记】。进行中 / 已完成已经是想清楚的任务,不给这个钮。
- **列在电脑上管理**(新建 / 改名 / 调顺序 / 删除),会同步到你的其它设备。两条规矩:「待办」与「已完成」**只能改名、不能删**(新任务落在待办,进已完成才算完成、才能归档);**删一列前要先把里面的卡移走**。
- ⚠ **多设备时有一道版本门**:要等这个账户里**所有设备都升到支持自定义列的版本**,这项才会打开,否则老版本的设备看不懂新列。没打开时面板里会写明原因。

## 标签

- 一条内容可以挂多个标签。合并标签会把碎标签并进存续的那个、重写归属,不丢内容。
- 想分层就用斜杠命名,比如建一个 `工作/汇报`:只要同名的 `工作` 标签也存在,它就在列表里缩进显示。
- ⚠ **层级只是看着有**:筛选、计数、合并都还把它当独立标签。筛「工作」**不会**自动包含「工作/汇报」;一条内容两边都想算,就两个标签都打上。

## 空间与「移动到其他空间」

- 空间有两条来路:**新建空间** = 开一本新册子,即建即用、纯本地(想多端同步就在那个空间里创建账户);**加入空间** = 把别处已有的账户接到本机(扫码或手输配对码)。
- 快速捕获落在**你当前所在的空间**;搜索和看板也只看当前空间,不跨空间混排。
- 把家人的设备配对进「家庭」空间的账户,你们两个就共用这一本;而**你个人空间的数据永远不出它自己的账户**。这个隔离是**加密边界**,不是权限开关。
- ⚠ **移动一条到别的空间 = 在目标空间重新诞生、在原空间删除**:标签按名字带过去、配图原编号带过去,但**编辑历史不随迁,会随这次移动永久删除**(选空间之前会提示你)。
- 移动中途万一出岔子,宁可两边各留一份也绝不弄丢,卡片上会明确标出来让你手动处理。

## 多设备同步

- 同步是**可选**的,不配置就完全离线使用,这个功能全程沉默。
- 默认走官方服务器 `sync.zhujian.app`,也可以换成自己搭的(怎么搭见[自建同步服务器](#自建同步服务器))。不要邮箱和手机号。
- 第一台设备点「创建账户」就开好了,不用抄任何东西;其余设备输入老设备生成的**配对码**加入,自动拿到全量数据,此后离线照用、上线互补。拿全量数据的那一会儿老设备要开着并联网;它不在线时新设备会说明原因,等它一上线自动接着拉。
- 内容在你的设备上加密之后才发出去,服务器经手的只有密文,读不到内容。
- ⚠ **账户密钥只在你自己的设备上**,服务器没有、也不做备份。**恢复数据始终要靠至少一台还留着完整副本的设备,或一份你自己做的加密备份文件**(下面「加密备份与备份码」那节);全部设备都丢了又没有备份,谁也帮不了。早期版本创建账户时会让你抄一串「恢复码」—— 它从来没有派上用场的地方,已经去掉;抄过的那串作废,不必再保管。

## 同一个 Wi-Fi 下的直连

- 两台设备在同一个局域网里时会自动**点对点直传**,不绕服务器:更快,而且**路由器断了外网也照样同步**。加密一点没变,直连和走服务器一样是端到端加密。
- 不需要设置,连不上就自动退回走服务器,你不会察觉。
- ⚠ **诚实说一句它的代价**:同一个局域网里的人虽然**看不到你的内容**,但**能看出「这两台设备正在同步」**,以及设备编号、内网地址、什么时候传了多少数据。这比服务器能看到的更多。在自己家的 Wi-Fi 上无所谓;在公司、咖啡馆这类公共 Wi-Fi 上,这些信息对同网的人是可见的。**目前没有关闭开关。**

## 设备名单与移除设备

- 同步面板里有一张**这个空间当前的设备名单**,一台一行,显示名字(没起过名的显设备编号前几位),标出「本机」与「管理设备」,点开看完整编号、可复制。名单是**服务器给的**,所以「哪台还在册」以它为准。
- 可以给每台设备起个名字。起过名之后,**别的设备**记下的条目会在时间那一行淡淡标出来源。三条克制的规矩:自己这台记的从不显、没起过名的设备不显、这功能上线前记的老条目一律不显。名字**会同步**给别的设备,并且是**按空间分别起的**。
- **谁能移除谁**:第一台创建账户的设备自动是管理设备,之后可以再指定别的。**只有管理设备能移除别人**;不是管理设备的那些,能且只能让**自己**退出。为免把人锁在门外,**管理设备不许被移空**:只剩一台时,它既不能被移除,也不能自助退出。
- ⚠ **移除意味着什么**(确认框里逐条写着,一句不省):
  - 被移除的设备**不能再经服务器同步**这个空间;
  - 但它本机**已有的内容不会被删除**,移除不是「清空它」;
  - 配对时交给它的**账户密钥和那份完整副本也拿不回来**(团队里尤其要想清楚这一点);
  - 同一个 Wi-Fi 下:还在册的设备**每台只要能从服务器取到最新名单,就会断开与它的局域网直连**,通常是立刻,网络不好时可能要等几分钟;那台取不到名单的仍可能继续直连。
- ⚠ **若它还有没同步出来的内容,先让它上线同步完再移除**:重新加入需要清空它那边的数据,期间它独有的东西找不回来。
- ⚠ **想彻底隔离**(设备丢了、共用一个空间的人要走干净),移除**不够**:数据是端到端加密的,密钥早就在对方手里了,只能重置整个账户(全部设备重新配对、账户密钥轮换)。要走这条路请[发邮件](#出了问题找谁)。

## 加密备份与备份码

**电脑端三件都有**:手动备份、定时自动备份、从备份恢复。⚠ **手机上能备份,但不能从备份还原** —— 真出事时把 `.zjbak` 文件拿到电脑上的朱简里恢复(手机上那一节写的是同一句)。⚠ **鸿蒙版还没有备份**,那一端也要到电脑上做。

- 「设置 → 备份与恢复」把**每个空间的完整数据**各加密成一个文件,存到你自己拿得到的地方(U 盘、网盘都行)。备份文件默认落在数据目录的 `backups/` 里,那一行也可以改成别的完整路径。
- **定时自动备份**在同一节里,开关只有一枚;开着之后,隔多久备一次、每个空间留最近几份,那一行会照实写出来。手动备份不进自动清理的账;万一自动那趟没跑顺,主窗右下角会弹一条提示。
- **从备份恢复**也在这一节,填备份文件的完整路径和**取这份备份那台设备的**备份码(这台机器有没有设置过备份都不影响,输进来的码不会被存下来)。四条边界照 app 里的原话:
  - 恢复**绝不覆盖任何现有数据**:它**新建一个空间**,原来的空间原样在那儿,要不要删由你决定;
  - 恢复出来的空间**不同步**,直到你给它创建账户、把别的设备重新加进来;它不会踢掉任何设备,也不会让旧账户消失;
  - 恢复回来的是备份那一刻的数据;同一台机器上恢复会多出一个空间,而且可能与原来那个同名;
  - 跑起来之后**不能取消、也没有进度**;过程中临时需要大约 3 倍于库大小的磁盘空间。
- 第一次要走一道**备份码**仪式:屏幕上给你一串码,你抄下来(纸上或密码管理器),再完整输回去核对一遍。这一步就是为了确认你真抄下了,不是走过场。
- **没有备份码,文件里的内容读不出来**,所以丢网盘、丢 U 盘、被网盘留了版本历史都不要紧。
- ⚠ **备份码,以及所有还存着这把钥的设备,全都失去之后,已有的备份文件谁也解不开,包括我**。没有找回通道。
- ⚠ **备份文件里含这台设备的同步身份与账户密钥**(否则将来恢复出来的库同步不了),所以**备份文件加备份码,就等于这个账户的完整读写能力**,当秘密保管。
- ⚠ **有备份 ≠ 不会丢**:备份是把保管权交到你手上,不是耐久性承诺。默认落点与主库同一块盘,想防硬盘坏就换个物理位置存。

## 更新与卸载

- 电脑上装好后会自动检查新版本并提示你;手机上提示之后要你自己点一下装。**更新包有开发者签名,装前会核对**。
- ⚠ **Windows 安装包没有做系统签名**(没买代码签名证书):第一次装的时候 Windows 会拦一下,说发布者未知。要装就点「更多信息 → 仍要运行」。macOS 与 Linux 的尝鲜版同样没签名,首次打开要在系统里手动放行。Android 的 APK 本身是签过的(安卓强制),但首次安装仍要你允许「未知来源」。
- ⚠ **手机上卸载应用会连数据一起清除**。
- ⚠ **电脑上卸载不会删掉数据目录,也不会删掉备份钥**。真要清干净得手动删,但删之前先确认**备份码另有一份独立副本**,否则你存在外面的备份可能永远解不开。

## 自建同步服务器

同步服务器只做三件事:转发加密后的数据、替暂时离线的设备存几天、帮两台设备完成配对。它读不到内容。官方服务器跑的就是源码仓库里 `server/` 这一份(程序名 `zhujian-syncd`),你自己也能跑一台。

先说清三件事:

- ⚠ **自建服务器上的账户是另一套,和官方服务器上的不互通。** 换服务器 = 在新服务器上重新创建账户、各台设备重新配对。已经在官方服务器上同步着的空间,要换过来得走下面「已经在用官方服务器,想换过来」那条路,**不是**改一下地址就行。
- **没有官方 Docker 镜像,也没有编译好的服务端程序**,只能从源码自己编。
- 自建的服务器,升级、备份、机器安全都**由你自己负责**;官方服务器升级时不会通知到你。

### 最小跑法

要一台装了 Rust(用 rustup 装稳定版就行)的 Linux 机器。把源码仓库([zhujian.app](https://zhujian.app) 上指向的那个)克隆下来,在仓库根目录:

```sh
cd server && cargo build --release
mkdir -p ~/zhujian-data
touch ~/zhujian-data/banlist.txt
./target/release/zhujian-syncd --listen 127.0.0.1:8787 --data-dir ~/zhujian-data
```

- 起来之后打一行 `INFO zhujian-syncd 监听 ws://127.0.0.1:8787/ws`。另开一个终端 `curl http://127.0.0.1:8787/healthz`,回 `ok` 就是活的。
- `banlist.txt` 是封禁表,自己用一直空着就行,但**文件必须在**,少了它会拒启(「读封禁表 … 失败」)。
- 一个数据目录只能跑一份:对同一个目录再起第二个,它会说「已被另一个 zhujian-syncd 进程占用」然后退出。
- 参数写错时它会把完整用法打出来。

**在 app 里用上它**:

- 第一台设备:「同步 → 创建账户(第一台设备)」,表单里的服务器地址默认是官方的,**改成你的**再点【创建】。
- 其余设备:在老设备上点【添加设备】,屏幕上会给出**服务器地址和配对码**;手机扫二维码时地址已经带在码里,不用另填,手输的话两项都照抄。
- 地址只认 `ws://` 或 `wss://` 开头,填到主机和端口为止(`/ws` 那段 app 会自己补)。
- 服务器和 app 在同一台电脑上:填 `ws://127.0.0.1:8787`。
- 在自己家的局域网里用:启动时改成 `--listen 0.0.0.0:8787`,各设备填 `ws://这台机器的局域网地址:8787`。⚠ **`ws://` 不加密连接本身**:内容照样是端到端加密的,但同一个网络里的人能看到有哪些设备在和服务器同步、账户号和设备号、什么时候传了多少。在自己家里无所谓,**别在公共网络上用 `ws://`**。

### 从外网用:要加 TLS

服务器自己只讲明文,对外要放在一个带 TLS 的反向代理后面。用 [Caddy](https://caddyserver.com) 最省事,它会自动申请证书:

```
sync.example.com {
	reverse_proxy 127.0.0.1:8787
}
```

- 把域名解析到这台机器、放行 80 与 443,重载 Caddy,app 里填 `wss://sync.example.com`。WebSocket 不需要额外配置,上面这三行就够了。
- ⚠ **证书必须是公开 CA 签的**(Caddy 默认用的 Let's Encrypt 就是)。app 只认内置的那份公共根证书列表,不读系统的证书库,所以**自签证书连不上**。
- `zhujian-syncd` 继续只监听 `127.0.0.1`,别直接暴露到公网。要它常驻,交给 systemd 之类的进程托管,挂了自动重启即可(`Restart=always`)。

### 已经在用官方服务器,想换过来

- ⚠ **「同步 → 高级… → 修改服务器」不是干这个的**。它只换地址、账户原样不动,是给**同一台服务器搬家**用的。拿它指向一台不认识这个账户的服务器,状态会一直显示「服务器拒绝(账户被封禁,或本设备未注册/已吊销)」并反复重试;改回原来的地址就好了。
- 要连数据一起搬:在电脑上「设置 → 备份与恢复」做一份备份,再用【从备份恢复】把它恢复出来。恢复出来的是一个**不同步的新空间**(见上面[加密备份与备份码](#加密备份与备份码)),在这个新空间里创建账户,服务器地址填你的,其它设备再配对加入。原来那个空间还在,要不要删由你决定。
- 不需要旧数据的话更简单:新建一个空间,在里面创建账户时填你的地址。

### 服务器上存着什么、该备份哪个

数据目录里只有三个文件,**没有任何内容**:不存正文、不存图片,也不存密钥。

- `registry.json`:账户号、设备号、设备公钥,以及哪台是管理设备。**要备份的就是它**。丢了,所有设备再连上来都会被拒(服务器不认识它们了),只能全部重新建账户、重新配对。服务器搬家的做法也就是带上它:在新机器上用同一份 `registry.json` 起服务,每台设备「修改服务器」改成新地址,就接着同步。
- `banlist.txt`:封禁表。
- `meters.json`:流量计量,丢了无妨。

替离线设备暂存的数据(信箱)**只在内存里**,最多存 72 小时,服务器一重启就没了。这不会丢数据:内容的真身在每台设备自己的库里,信箱只是让同步快一点;两台设备下次同时在线时会互相对一遍账,缺的自动补上。真正会丢的只有一种情况 —— 某台设备上还没同步出去的内容,跟着它的硬盘一起坏了,这跟用谁的服务器无关。

服务器的运行日志打在标准错误里:连接时刻、账户号与设备号、传了几帧多少字节,不含内容。

### 另外两个参数

- `--free-seat-quota N`:每个账户能挂几台设备。**默认只有 2 台**,第三台配对时老设备会提示「同步席位已满:请先移除一台不用的设备,再添加新设备」。自己用就调大,比如 `--free-seat-quota 8`;服务端对每个账户另有一个设备数上限,调得再大也不会超过它。
- 管理口(可选,不开完全不影响同步):`--admin-listen 127.0.0.1:8788 --admin-token-file <token 文件>`,用来从服务器侧吊销设备。只许绑回环地址,**别放进反向代理**;token 文件用 `openssl rand -hex 32` 生成、`chmod 600`,两个参数必须一起给。
