常见问题

遇到了先看这里

同步好像不动了?

先看两头是不是都开着、连着网。手机上的朱简要在前台才会追赶,放到后台不保证实时。新设备刚加入的那一会儿,老设备也要开着,才拉得到全部数据。

都开着还是不动,就跑一遍网络自检:电脑在「设置 → 关于 → 诊断」,手机在「设置 → 诊断」。它会一步步检查,告诉你卡在哪一步。还不行就发邮件给我。电脑上那一页最下面一行能把诊断结果复制成一段文字,贴进邮件就行;手机上截个图也可以。

手机丢了怎么办?

你别的设备上还有一份完整的数据,丢的只是这一台手机。在还在手上的设备里打开「同步」的设备名单,把丢的那台移除,它就不能再通过服务器同步了。

有两件事要知道。第一,移除收不回它本机已经有的内容。朱简没有单独的应用锁,这部分只能靠手机自己的锁屏挡着。第二,只有带「管理」标记的设备能移除别的设备。如果丢的正好是唯一一台管理设备,或者你想彻底隔离、把整个账户的密钥换掉,请发邮件给我。

如果丢的是你唯一的一台设备,又没做过备份,数据就找不回来了。谁也帮不了,包括我。

换了新手机(或新电脑),数据怎么搬过去?

旧设备还在的话,不用手动搬。在旧设备的「同步」里点「添加设备」,新设备装好朱简后,在「同步」里扫码或者输入配对码加入,全部数据会自动拉过来。拉数据的时候,旧设备要开着,手机的话要亮屏、停在朱简里。

以前没开过同步也一样:先在旧设备的「同步」里创建账户(不要邮箱和手机号),然后照上面的步骤加新设备。

在新设备上确认内容都齐了,再去设备名单里把旧的那台移除。手机上卸载朱简会把数据一起删掉,所以旧手机先别急着卸。

要花钱吗?

现在免费使用,包括多设备同步。你的数据存在你自己设备上的一个 SQLite 文件里,代码也开源(MIT)。哪天不想用了,东西都还在你手上。

给爱折腾的人

数据、键盘和源码

数据就是一个 SQLite 文件

电脑上的主空间在这儿,别的空间是同一目录下以一串编号命名的文件:

Windows  %APPDATA%\app.zhujian.notebook\notebook.sqlite3
macOS    ~/Library/Application Support/app.zhujian.notebook/notebook.sqlite3
Linux    ~/.local/share/app.zhujian.notebook/notebook.sqlite3

随记和待办在同一张 items 表里,靠它落在哪一列来区分。看最近五条随记:

sqlite3 notebook.sqlite3 "select i.created_at, i.content
  from items i join board_column c on c.id = i.stage
  where c.kind = 'idea' and i.archived_at is null
  order by i.created_at desc limit 5;"

建议只读着看。直接改它不在应用照顾的范围里,改坏了我也不好帮你救。手机上的库在应用私有目录里,拿不到。

不想碰数据库也行:电脑版设置 →「备份与恢复」→「导出为 Markdown」,把整个空间连图带留言导成几份 .md,任何编辑器都能打开。

手不离键盘

  • Ctrl+Alt+N 唤出纸条,Ctrl+Alt+M 打开主窗;两个都能改。Mac 上是 Cmd+Alt。
  • 纸条里行首打 /:/task 直接存成任务,/tag 名字 挂上标签,/space 换个空间。
  • 卡片右上角 ⋯ 里每项都标着单键:E 编辑、C 复制、L 标签、S 截止、P 优先级、B 撤回、D 删除,] 和 [ 前后挪一列。
  • 正文行首写 - [ ] 就是一个能勾的方框。
