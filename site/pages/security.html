隐私与安全

你的数据在哪,谁看得到

朱简把数据存在你自己的设备上。下面是几件先说清的事,和开了同步之后服务器看得到什么。

几件事先说清
数据在哪
在你自己设备上的 SQLite 数据库里。不联网也照常用;开了同步的设备,回到网上再互补。
账号
不用注册。要多设备同步时,点「创建账户」就行,不要邮箱和手机号,也不用抄任何码。账户密钥只在你自己的设备上,服务器没有。
同步
可选,端到端加密。文字和图片在你的设备上加密后才发出;服务器经手的只有密文,读不到内容;它不做备份,找回数据靠你自己的设备。同一个 Wi-Fi 下的两台设备直接互传,不经服务器;同网的人看不到内容,但能看出它们在同步。
统计
没有统计代码。不开同步时,应用只会连 zhujian.app 查有没有新版本。
AI
没有。不替你归类,不改你写的字;早期做过,已经删掉。
免费与开源
免费使用,含多设备同步。开源(MIT),源码在 GitHub。
同步服务器

它看得到什么,看不到什么

开了同步,数据要经服务器转一手。下面照协议原样列出来。

看不到

  • 随记和任务的内容,以及改过的旧版本
  • 图片
  • 标签名、看板列名、设备名
  • 每一次改动是新建、编辑还是删除
  • 账户密钥

看得到

  • 账户编号和设备编号(随机生成的一串字符)与各设备的公钥
  • 哪台设备什么时候在线
  • 什么时候发了数据、发了多少。由此能推出你大概什么时候在用
  • 连接从哪个 IP 地址来

服务器硬盘上只存这几样:账户和设备的编号与公钥、哪台设备有管理权限、账户的设备额度、封禁名单、流量计量,以及不含内容的连接日志。设备离线时,发给它的密文在服务器内存里等它,72 小时没取走就丢掉,服务器重启也会清空;数据本身在你的设备上,回到网上会重新补齐。

有一件事协议管不了:你得相信装到手上的安装包,就是 GitHub 上那份开源代码编出来的。不放心的话,可以自己编译。
